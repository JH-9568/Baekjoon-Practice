# Baekjoon Practice

백준 파이썬 연습 기록용 (1일 1커밋)

## 폴더 구조

- `bronze/` : 브론즈 문제
- `silver/` : 실버 문제
- `gold/` : 골드 문제
- `platinum/` : 플래티넘 문제
- `templates/` : 풀이 템플릿

## 파일명 규칙

문제번호 기준으로 저장.

예시:
- `bronze/1000.py`
- `silver/1920.py`
- `gold/11066.py`

## 풀이 방식

1. 문제번호 파일 생성
2. 로컬에서 실행 확인
3. 백준에 제출
4. 정답이면 커밋 후 push
