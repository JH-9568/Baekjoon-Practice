# Baekjoon Practice

백준 문제 풀이 연습(1일 1커밋 이상 목표) 
정답 제출 후 **BaekjoonHub**를 통해 GitHub 저장소에 자동 업로드되도록 설정
## Repository Structure

- `백준/` : 백준허브가 자동으로 업로드한 백준 문제 풀이
  - 난이도별 폴더
  - 문제 번호 / 문제명 기준 정리

## Workflow

1. VS Code 또는 로컬에서 문제 풀이
2. 백준에 제출
3. 정답 판정 시 BaekjoonHub가 자동으로 GitHub에 업로드
4. 저장소에서 풀이 기록 관리
